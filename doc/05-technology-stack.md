## Why Spring AI + LangChain4j?

### Spring AI

- Native Spring Boot integration
- ChatClient API
- Embedding abstraction
- Vector store integration

### LangChain4j

- AI Tools
- SQL Agent
- Multi-agent patterns
- Memory support

Spring AI becomes the infrastructure layer, while LangChain4j provides agent capabilities.
